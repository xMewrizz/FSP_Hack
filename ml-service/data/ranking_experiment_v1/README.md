# Учебный набор для ранжирования

Все профили, результаты тестов и запросы в этой папке вымышлены. Набор нужен для разработки обучения и проверки кода модели. Он не показывает качество подбора на реальных людях.

`candidates.json` содержит 90 кандидатов с подтверждённым в симуляции грейдом Backend, `needs.json` — 48 потребностей, `pairs.jsonl` — 648 допустимых пар. У каждой пары есть `pair_id`, `need_id`, `candidate_id`, `split`, `label`, `reason` и `label_source`. Целевая метка: 0 — не подходит, 1 — можно рассмотреть, 2 — подходит. Она получена из отдельного правила по навыкам, формату, городу и зарплате. Балл В-14 при создании меток не использовался.

| Часть | Потребностей | Кандидатов | Пар | Меток 0 / 1 / 2 |
|---|---:|---:|---:|---:|
| train | 30 | 54 | 540 | 238 / 259 / 43 |
| validation | 9 | 18 | 54 | 18 / 27 / 9 |
| test | 9 | 18 | 54 | 22 / 21 / 11 |

Кандидаты и потребности не пересекаются между частями. В обучении используйте только пары `train`; настройки подбирайте по `validation`. `test` нужен для одной итоговой проверки выбранного варианта. В признаки можно брать навыки, результат подтверждённого теста, формат и город работы, ожидания по зарплате и достижения ФСП. Не используйте `label`, `reason`, `split`, ID, код профиля или код потребности как признаки: часть из них раскрывает ответ или позволяет запомнить строки набора.

Повторить создание данных и сравнение текущей формулы с простой сортировкой:

```bash
python ml-service/build_ranking_experiment.py
python ml-service/evaluate_ranking_experiment.py
```

Для оценки своей модели сохраните JSONL с полями `pair_id` и числовым `score` для **всех** пар `validation` и `test`, затем запустите:

```bash
python ml-service/evaluate_ranking_experiment.py --predictions путь/к/predictions.jsonl
```

Скрипт покажет Precision@3, nDCG@5 и число запросов, где подходящий кандидат стоит первым. Сравнивайте модель с простой сортировкой и В-14 на одних парах. Даже хороший результат здесь означает только то, что модель научилась работать с синтетическим правилом меток. Для выводов о качестве продукта нужны реальные ответы на тест и оценки работодателей по реальным кандидатам.
