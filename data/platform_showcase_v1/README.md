# Демонстрационные данные для стенда

Это 60 вымышленных кандидатов (по 10 на каждую пару Backend/Data Science ×
junior/middle/senior), 8 компаний, 15 вакансий и 6 заданий. Исходные данные
созданы скриптом `generate.py`. Все email относятся к зарезервированному домену
`example.test`; реальные контакты, рабочие резюме и действующие сайты в БД не
переносятся.

Файлы JSON сами по себе не наполняют сайт. После обновления сервера импорт
запускается отдельно из корня репозитория:

```powershell
.\deploy\import-showcase.ps1
```

Повторный запуск ничего не дублирует. Импорт создаёт неактивные аккаунты,
поэтому их нельзя использовать для входа. В поиске кандидатов анкеты помечены
`(демо)` и бейджем `ДЕМО`; у компаний, вакансий и заданий есть префикс `Демо`.
Алгоритм подбора работает на импортированных результатах тестов, но
демонстрационные достижения ФСП не дают бонуса к ранжированию.

Работодатель может создать демо-приглашение вымышленному кандидату и писать в
демонстрационном диалоге. Приглашение и сообщения сохраняются в БД. Анкета
неактивна: кандидат не принимает приглашение и не отвечает. Контакты не
раскрываются. Отклик на вымышленную вакансию и отправка ответа по вымышленному
заданию отклоняются с пояснением; для показа этих сценариев нужны действующие
тестовые аккаунты. Демонстрационные кандидаты не появляются в поиске наставников.

Проверить исходные файлы и импорт локально:

```powershell
cd backend
.venv\Scripts\python.exe -m pytest -q tests/test_showcase_seed.py
```
