# Бэклог проекта

Рабочий план команды. `P0` — основной сценарий к сдаче, `P1` — после него, `P2` — если останется время. Строки внутри каждого приоритета расположены по зависимостям; параллельные задачи можно начинать раньше. ID идут в том же порядке, что и задачи в таблице. «Да» ставим только после проверки всей задачи.

На 7 октября 2026 года есть frontend, API, миграции и тесты. Backend пока не стартует: в репозитории нет `backend/app/models`. `uv run pytest -q` останавливается до запуска тестов с ошибкой `No module named 'app.models'`. Независимые от backend задачи можно завершать; сквозные сценарии ждут B-00.
