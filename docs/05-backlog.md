# Бэклог проекта

Рабочий план команды. `P0` — основной сценарий к сдаче, `P1` — после него, `P2` — если останется время. Строки внутри каждого приоритета расположены по зависимостям; параллельные задачи можно начинать раньше. ID идут в том же порядке, что и задачи в таблице. «Да» ставим только после проверки всей задачи.

На 7 октября 2026 года: проблема с игнорированием каталога `models/` в `.gitignore` устранена, все модели ORM (`backend/app/models`) зафиксированы в репозитории. Все 6 интеграционных тестов backend успешно проходят (`uv run pytest -v` — 100% успех за ~2.7 сек). Все ключевые бэкенд-сервисы и эндпоинты сценария P0 реализованы и готовы к подключению фронтенда.
