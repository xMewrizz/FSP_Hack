# 05 — Бэклог v1 (волны, зависимости, стек)

Легенда: `Must` = блокер MVP/демо, `Should` = сильно усиливает оценку, `Nice` = только если всё зелёное.

### Как читать ID
- `B-XX` — просто номер задачи в бэклоге (B = backlog). Нумерация сквозная, не по приоритету.
- `B-13b, B-14b` — буква `b` = вторая часть той же задачи. `B-13` (NLP извлёк навыки) → `B-13b` (ползунки весов + job radar). `B-14` (подборка списком) → `B-14b` (overlay-график поверх неё). Без базовой `B-13` делать `B-13b` нельзя.
- `B-19Mock` — суффикс `Mock` = заглушка на MVP: вместо реальной интеграции/OSINT-скоринга — захардкоженные правила + предзаписанный `fsp-mock.json`. Интерфейс настоящий, данные фейковые, потом заменяем без переписывания API.
- `B-06x` — суффикс `x` = сквозная/расширяющая задача (cross): словарь adjacent skills, используется и в тестах, и в подборе. Не блокирует, встраивается поверх.
- `(п.7)`, `(★)` в описании — откуда пришло: номер из исходного списка Айгюль / звёздочкой помечены фичи-усилители из конца списка.
Стек общий: **Backend Python 3.12 + FastAPI + SQLAlchemy 2 + Alembic + Pydantic v2 + Postgres 16 + Redis** | **Frontend React 18 + Vite 5 + Tailwind + Router + TanStack Query + Recharts** | **ML-service Python + Qwen2.5:14B (Ollama) + BGE-M3/E5 + PyMuPDF + natasha/spaCy + scikit-learn** | **Docker + compose**.

## Порядок запуска (что за чем, по шагам)

Читается сверху вниз: следующий шаг можно начинать, только когда готов предыдущий в его цепочке.

**Шаг 1 — фундамент (день 1):**
`B-00` (compose, БД, Swagger) → дальше два независимых хвоста.

**Шаг 2 — две ветки от фундамента:**
- Ветка А (люди): `B-00 → B-01` (auth) `→ B-02` (онбординг) `→ B-03` (PDF-парсинг) `→ B-04` (профиль + PDF).
- Ветка Б (тесты): `B-00 → B-05a` (справочники) `→ B-07` (банк 500–1000) `→ B-08` (CAT-подача) `→ B-09` (проверка) `→ B-10` (грейд) `→ B-11` (downshift/кулдаун).

**Шаг 3 — работодатель (ждёт B-01 + B-05a + B-10):**
`B-12` (компания) `→ B-13` (NLP потребности) `→ B-13b` (веса + job radar) `→ B-14` (подборка, сюда же подклеиваются B-18 Trust, B-19Mock антифрод, B-20 ФСП).

**Шаг 4 — от подборки расходятся три независимые задачи:**
- `B-14 → B-15` (пригласить) `→ B-16` (принять/отклонить) `→ B-22` (витрина вакансий, только P2);
- `B-14 → B-17` (поиск с фильтрами);
- `B-14 → B-14b` (gap-overlay, вау-эффект).

**Шаг 5 — фоном параллельно:**
- `B-24` (синтетика) можно делать с дня 1, а `B-23` (валидация) стартует когда готовы `B-24 + B-10 + B-14`;
- `B-21` (микрозадачи) ждёт `B-09 + B-14`;
- `B-25/26/27/28` — после ядра.

**Критический путь демо (если горит — только это):**
`B-00 → B-01 → B-05a → B-02 → B-07 → B-08 → B-09 → B-10 → B-12 → B-13 → B-13b → B-14 → B-15 → B-16 → B-20 → B-23 → B-29`.
Первыми режем: `B-22, B-21, B-14b, B-18, B-06x` (в таком порядке).
