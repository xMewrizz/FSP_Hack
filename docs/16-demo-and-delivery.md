# Показ проекта и материалы к сдаче

## Публичный стенд для организаторов

Рабочий адрес: **https://fsphack.xmewrizz.ru/**. Стенд открывается без VPN и
не требует доступа к репозиторию. Для самостоятельного просмотра зарегистрируйте
две учётные записи с разными email: кандидата и работодателя. На тестовом стенде
код подтверждения регистрации показывается прямо на экране, письмо не требуется.

Быстрый маршрут работодателя: заполнить профиль компании → создать потребность
Backend или Data Science / ML → открыть «Подборку» → выбрать синтетического
кандидата с пометкой «ДЕМО» → отправить демо-приглашение → открыть «Диалоги».
Демо-приглашение и сообщение сохраняются в БД; синтетический кандидат не отвечает
и его контакты не раскрываются. Это позволяет показать механику приглашения и чата
без выдачи вымышленных данных за реальный отклик.

Для полного теста кандидата используйте отдельную учётную запись. Если модель
временно недоступна, ответ открытого задания не теряется: интерфейс сообщает
«Попробуйте позже», а проверку можно повторить после восстановления сервиса.

## Короткое описание для промежуточной заявки

ФСП.Карьера помогает работодателю найти кандидата по подтверждённой специализации и грейду и самому отправить приглашение. Кандидат сначала выбирает направление и предполагаемый грейд, затем проходит одинаковые для своего направления обязательные блоки навыков. Рабочие базовые наборы есть для Backend на Python и Data Science / ML: обязательные навыки и вопросы разделены по Junior, Middle и Senior. Темы сохраняются между грейдами, сложность заданий меняется. Вопросы и запасные варианты фиксируются на время попытки, а для пересдачи используется другой вариант. Так результаты внутри одного грейда можно сравнивать, не выдавая всем дословно один и тот же тест. Качество формулировок и различение грейдов ещё проверяются.

Подбор допускает только опубликованные профили с подтверждённой нужной категорией; заявленный грейд сам по себе доступа не даёт. Внутри категории кандидаты ранжируются по результатам навыков, требованиям работодателя и достижениям ФСП. Карточка показывает причины рекомендации. На небольшом синтетическом наборе мы сравнили этот порядок с простой сортировкой по совпадению навыков; цифры и ограничения приведены ниже. Контакты раскрываются работодателю после принятия приглашения кандидатом.

## Что можно показать сейчас

Основной путь после изменения B-27: регистрация кандидата, профиль, тест навыков, два открытых задания, результат, подбор работодателя, приглашение и ответ кандидата. Для Backend доступны Python и грейды Junior, Middle, Senior; для Data Science / ML обязательные навыки включают Python, Pandas, SQL, статистику, A/B-тестирование и машинное обучение. Набор открыт три дня; пороги 75% в целом и 50% по каждому шагу предварительные. Ответы сохраняются до проверки моделью; во время проверки можно решать следующие задания. Для подтверждения нового грейда нужна доступная модель или ручная проверка открытых ответов. Сквозной путь Backend Junior повторно пройден в браузере на локальном PostgreSQL 10 октября: для проверки аккаунты и профили подготовили через API, затем в интерфейсе отправили два открытых ответа, прошли тесты, получили подтверждённый грейд, выполнили подбор, приглашение и принятие. После проверки тестовый профиль скрыт из общей выдачи. Путь до грейда с ручной проверкой отдельно пройден через API на изолированном PostgreSQL.

На 9 октября 2026 года запуск проверен на отдельном Compose-проекте с пустой базой. Скрипт `backend/smoke_compose.py` прошёл путь от регистрации двух учётных записей до принятия приглашения. Это проверка работы системы, а не оценка качества заданий людьми.

## Самостоятельный проход

1. Откройте [публичный стенд](https://fsphack.xmewrizz.ru/). Для локального запуска это `http://localhost:5173`; команды приведены в [инструкции](03-api-and-run.md).
2. Зарегистрируйте кандидата. Код подтверждения на публичном тестовом стенде показывается на экране. Заполните профиль и выберите Backend или Data Science / ML с предполагаемым грейдом.
3. В разделе «Тестирование» откройте набор, пройдите обязательные тесты навыков и отправьте два развёрнутых ответа. Задания фиксируются при создании набора. Итог по грейду появится после завершения набора и, если требуется, ручной проверки. В профиле можно посмотреть баллы по навыкам и историю.
4. Зарегистрируйте работодателя с другим email, заполните компанию и создайте потребность по Backend или Data Science / ML. Откройте подборку, изучите объяснение, True Score и статус ФСП, затем отправьте приглашение с условиями и зарплатой.
5. Вернитесь в аккаунт кандидата, примите приглашение. Работодатель увидит статус и контакты после принятия.

Прохождение набора из 42 заданий занимает столько времени, сколько потребуется человеку; обещать короткое прохождение нельзя. Для быстрого обзора интерфейса можно использовать демонстрационные данные, но они не заменяют самостоятельное прохождение теста. При отсутствии LLM открытые ответы ждут ручной проверки, и грейд пока не присваивается. Достижения ФСП в демо берутся из локальных тестовых данных.

## Цифры и ограничения для презентации

- Базовый Backend-тест: четыре обязательных навыка, по десять заданий на навык, три грейда. Банк и ключи проходят технические проверки; сложность заданий на ответах людей пока не оценивалась (B-32).
- В техническом сравнении подбора формула B-14 поставила кандидата с наивысшей меткой первым в трёх из трёх синтетических потребностей. Простая сортировка поставила его вторым. `nDCG@4`: 1,000 против 0,797; `P@3`: 0,333 у обоих подходов. Это небольшой синтетический набор с предварительными метками, а не доказательство качества на реальных работодателях. Методика и таблица — в [сравнении](09-ranking-review.md).
- Качество порогов, заданий и подбора на реальных людях пока не проверено; эта работа вынесена в B-32.
