# Дополнительные навыки кандидата (B-44)

Дополнительный навык проверяется отдельной попыткой и не входит в расчёт грейда. Тест доступен кандидату после заполнения профиля и согласия с условиями тестирования; подтверждённый грейд для старта не нужен. Сложность и порог одинаковы для Junior, Middle и Senior. Смена грейда не удаляет результат.

## Банк

Банк находится в `backend/app/core/additional_skill_bank.py`. Доступны Git и Docker для Backend и Data Science / ML; Redis и кэширование для Backend; подготовка данных, оценка моделей, развёртывание моделей и анализ данных для Data Science / ML. На каждый навык подготовлены две формы по пять разных заданий (70 заданий всего). Первая пересдача использует другую форму. Формы чередуются на дальнейших попытках; варианты выбора перемешиваются при старте. Открытые ответы входят в ту же последовательность вопросов и находятся в конце формы по Redis, подготовке данных и развёртыванию моделей.

Закрытое задание даёт 1 балл за верный ответ. Открытое даёт от 0 до 2 баллов по доле оценки модели. Навык подтверждается при `score / max_score >= 0.75`; округлённый процент используется только для отображения. При недоступности модели результат не выставляется и попытка остаётся открытой. Кандидат видит «Не удалось проверить ответ. Попробуйте снова» и может отправить тот же ответ повторно.

Повторный старт до истечения семи суток после **завершения** попытки отклоняется с `429`. Незавершённая попытка открывается повторно без расходования пересдачи. Если кандидат уже подтвердил навык, более слабая последующая попытка сохраняется в истории, но не отзывает подтверждённый результат.

В профиле кандидата показываются только подтверждённые дополнительные навыки. В подборе работодателя их результаты сопоставляются с навыками потребности по отдельным кодам и не привязываются к текущему грейду. Неподтверждённый результат не повышает оценку подбора.

Проверка: `backend/.venv/Scripts/python.exe -m pytest backend/tests/test_additional_skill_tests.py -q`, `cd frontend && npx tsc --noEmit && npm run build`.
