# Базовые навыки по специализациям: рабочее предложение

Состав ниже нужен для планирования банков заданий. Рабочие базовые тесты для присвоения грейда есть для Backend на Python и Data Science / ML. Остальные строки не означают, что тест уже доступен. Перед открытием нового направления нужно согласовать обязательные навыки с людьми, которые работают в нём, подготовить задания Junior, Middle и Senior и проверить результаты на пробных прохождениях.

Один навык может входить в базовый набор нескольких специализаций. При этом задания должны проверять его в рабочем контексте выбранной роли: Python для Backend и Python для Data Science не считаются одной и той же проверкой. Язык программирования кандидат выбирает перед базовым набором из тех языков, для которых готов банк. Другие языки можно подтверждать дополнительно после появления заданий. Git, Docker, Spark, CI/CD, FastAPI и отдельные инструменты не становятся обязательными для всех только потому, что они распространены.

| Специализация | Предлагаемые обязательные блоки | Что уточнить перед подготовкой тестов | Основание |
|---|---|---|---|
| Backend | Язык для серверной разработки; SQL и данные; HTTP API и интеграция; надёжность сервиса | Сейчас поддержан Python. Для Java, Go и других языков нужны отдельные задания; SQL и HTTP можно использовать повторно после проверки контекста. | [SFIA: разработка ПО](https://sfia-online.org/en/sfia-9/sfia-views/software-engineering-competencies/core-software-engineering-competencies), [RFC 9110](https://www.rfc-editor.org/rfc/rfc9110.html) |
| Frontend | JavaScript или TypeScript; HTML и доступность; CSS и адаптивная вёрстка; работа с состоянием и HTTP API | Решить, считать ли конкретный фреймворк обязательным или дополнительным навыком. Проверять не только знание синтаксиса, но и поведение страницы в браузере. | [MDN: программа веб-разработки](https://developer.mozilla.org/en-US/docs/Learn_web_development/Core) |
| Fullstack | Клиентская часть; серверный язык; HTTP API; SQL и данные; сквозная интеграция и отладка | Нужны два языка или пара «язык фронтенда + язык сервера». Один короткий тест не должен выдавать полное подтверждение обеих сторон. | [SFIA: разработка ПО](https://sfia-online.org/en/sfia-9/sfia-views/software-engineering-competencies/core-software-engineering-competencies), [MDN](https://developer.mozilla.org/en-US/docs/Learn_web_development/Core) |
| Mobile | Язык выбранной платформы; состояние и жизненный цикл приложения; работа с сетью и локальными данными; интерфейс и тестирование | Сначала выбрать платформу Android, iOS или кроссплатформенную разработку: общий ярлык Mobile скрывает разные рабочие задачи. | [Android: архитектура приложения](https://developer.android.com/topic/architecture), [Apple: разработка приложения](https://developer.apple.com/tutorials/develop-in-swift/welcome-to-app-development) |
| DevOps / SRE | Linux и сеть; автоматизация и конфигурация; контейнеры и развёртывание; наблюдаемость; надёжность и реагирование на сбои | Конкретный облачный провайдер и инструмент CI/CD можно проверять отдельно. Задания должны включать диагностику и решения при отказах. | [SFIA: DevOps](https://sfia-online.org/en/sfia-9/sfia-views/devops-view), [Google SRE: мониторинг](https://sre.google/sre-book/monitoring-distributed-systems/) |
| Data Science / ML | Python для анализа данных; SQL; подготовка данных и Pandas; вероятность и статистика; эксперименты и A/B-тесты; построение и оценка ML-моделей | Состав блока экспериментов зависит от задач роли. Spark и развёртывание моделей могут быть отдельными навыками. Python здесь проверяется на данных, а не на устройстве HTTP-сервиса. | [ACM: компетенции Data Science](https://www.acm.org/binaries/content/assets/education/curricula-recommendations/dstf_ccdsc2021.pdf), [SFIA: данные и аналитика](https://sfia-online.org/en/sfia-9/sfia-views/big-data-data-science) |
| QA / Testing | Анализ требований; проектирование тестов; API и данные; отчёт о дефекте; автоматизация на выбранном языке | Разделить ручное тестирование и автоматизацию либо явно указать язык и долю автоматизации в базовом наборе. | [ISTQB: программа Foundation Level](https://www.istqb.org/sdm_downloads/istqb-certified-tester-foundation-level-syllabus-v4-0/) |
| System Programming / C++ | C++ и управление ресурсами; память и владение; многопоточность; ОС и системные интерфейсы; диагностика производительности | Определить целевую платформу и стандарт C++; embedded, драйверы и высоконагруженные серверы требуют разных прикладных задач. | [C++ Core Guidelines](https://github.com/isocpp/CppCoreGuidelines), [ACM CS2023: области системного ПО](https://csed.acm.org/wp-content/uploads/2025/11/CS2023-Report.htm) |
| GameDev | Язык и движок; игровой цикл и логика; физика и математика; ресурсы и сцены; профилирование | Разделить клиентскую игру, серверную разработку и работу на конкретном движке. Unity/C# и Unreal/C++ нельзя оценивать одним языковым тестом. | [Unity: физическая симуляция](https://docs.unity3d.com/Manual/physics-optimization-cpu-manual-simulation.html), [Unity: профилирование](https://docs.unity3d.com/2022.2/Documentation/Manual/profiler-profiling-applications.html) |

Это наше предложение по структуре тестов, составленное по открытым рамкам компетенций и документации платформ. Источники описывают области работы, но не задают единственный правильный набор навыков для каждой вакансии и не подтверждают границы Junior, Middle и Senior. Перед реализацией стоит отдельно проверить долю каждого блока, нужные языки и типы заданий. Задания с открытым ответом и кодом остаются в B-27.
