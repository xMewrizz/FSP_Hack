# Как кандидат подтверждает грейд

Кандидат выбирает специализацию, язык программирования и грейд, который хочет подтвердить. Система показывает обязательные навыки выбранной специализации отдельными шагами. Список навыков одинаков для Junior, Middle и Senior; задания внутри каждого шага зависят от грейда. Сейчас рабочий набор есть только для Backend на Python: Python для Backend, SQL и работа с данными, HTTP API и интеграция, надёжность сервиса. В каждом шаге по десять самостоятельных вопросов.

Набор открыт три дня. При открытии система фиксирует задания, запасные варианты и правила подсчёта; обновление банка не меняет начатую попытку. Шаги можно проходить в разные дни. Результат каждого навыка показывается отдельно: например, «Python для Backend — 6 из 10 на уровне Middle». Эта оценка относится только к заданиям выбранного грейда.

**Грейд подтверждается после всех обязательных шагов.** В новом Backend-наборе это четыре теста навыков по десять вопросов, один развёрнутый ответ и одна задача с кодом. Каждый из шести шагов даёт до 10 баллов; результаты тестов нормализуются к этой шкале, поскольку вес вопросов разных грейдов может различаться. Нужно набрать не менее 45 из 60 баллов суммарно и не менее 50% на каждом шаге. Ровно 75% и ровно 50% проходят. Порог сравнивается без округления. Если открытый ответ ждёт ручной проверки, итогового решения пока нет.

Если в навыке меньше 50%, кандидат сразу видит результат и продолжает остальные шаги. После завершения полного набора можно **один раз пересдать весь набор** на том же грейде. Пересдача открывает отдельный набор на три дня с запасными вариантами тестовых вопросов; результаты двух наборов не смешиваются. Для открытых заданий запасные задачи ещё нужно подготовить — сейчас на том же грейде повторяются их формулировки. После второй неудачи система предлагает полный набор на ступень ниже, но не понижает ранее подтверждённый грейд. Если не подтверждён Junior, новый цикл Junior доступен через неделю после пересдачи. Незавершённый набор истекает через три дня без присвоения грейда; отправленные вовремя ответы, ожидающие ручной проверки, сохраняют набор до решения проверяющего.

Для повышения кандидат проходит полный набор на одну ступень выше по тем же правилам. Начать повышение можно через 90 дней после последнего успешного присвоения грейда. Дополнительные навыки проверяются отдельно на уровне текущего подтверждённого грейда и не влияют на итог базового набора.

**Пороги предварительные.** Модельная оценка открытого ответа от 75% учитывается автоматически; меньший результат, сбой модели и её запрос на проверку требуют ручного решения. На подготовленном бенчмарке модель пропускала зачётные ответы, поэтому качество присвоения грейда нужно проверить на ответах людей разных уровней (B-32). Отсутствие модели теперь задерживает подтверждение нового грейда.
