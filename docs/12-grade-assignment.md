# Как кандидат подтверждает грейд

Кандидат выбирает специализацию, язык программирования и грейд, который хочет подтвердить. Система показывает обязательные навыки выбранной специализации отдельными шагами. Список навыков одинаков для Junior, Middle и Senior; задания внутри каждого шага зависят от грейда. Сейчас рабочий набор есть только для Backend на Python: Python для Backend, SQL и работа с данными, HTTP API и интеграция, надёжность сервиса. В каждом шаге по десять самостоятельных вопросов.

Набор открыт три дня. При открытии система фиксирует задания, запасные варианты и правила подсчёта; обновление банка не меняет начатую попытку. Шаги можно проходить в разные дни. Результат каждого навыка показывается отдельно: например, «Python для Backend — 6 из 10 на уровне Middle». Эта оценка относится только к заданиям выбранного грейда.

**Грейд подтверждается после всех обязательных шагов**, если кандидат набрал не менее 75% баллов суммарно и не менее 50% в каждом навыке. Ровно 75% и ровно 50% проходят. Для текущего набора из 40 равновесных вопросов это минимум 30 верных ответов в целом и минимум 5 из 10 в каждом шаге. Проценты сравниваются без округления; округляется только отображение результата.

Если в навыке меньше 50%, кандидат сразу видит результат и продолжает остальные шаги. После завершения полного набора можно **один раз пересдать все четыре навыка** на том же грейде. Пересдача открывает отдельный набор на три дня с запасными вариантами заданий; результаты двух наборов не смешиваются. После второй неудачи система предлагает полный набор на ступень ниже, но не понижает ранее подтверждённый грейд. Если не подтверждён Junior, новый цикл Junior доступен через неделю после пересдачи. Незавершённый набор истекает через три дня без присвоения грейда.

Для повышения кандидат проходит полный набор на одну ступень выше по тем же правилам. Начать повышение можно через 90 дней после последнего успешного присвоения грейда. Дополнительные навыки проверяются отдельно на уровне текущего подтверждённого грейда и не влияют на итог базового набора.

**Пороги предварительные.** Сейчас задания только с выбором ответа. Вопросы и варианты ответа ещё нужно доработать и проверить на людях разных уровней: сам факт набора 75% пока нельзя считать надёжным доказательством квалификации.
